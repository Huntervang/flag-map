# 🌍 Flags of the World — Map Explorer

An interactive web map that displays flags at their geographic locations using MapLibre GL and OpenFreeMap.

Hosted at: [https://huntervang.github.io/flag-map/](https://huntervang.github.io/flag-map/)

## Features

- **Interactive Map**: Pan and zoom around the world to view flags.
- **Detailed Popups**: Click any flag to view a larger image and its Wikipedia page.
- **Fast Search**: Search for countries instantly with automatic map pan/zoom (`flyTo`).
- **Zero Build Step**: Built with plain HTML, CSS, and modern JavaScript modules.

## Tech Stack

- **Map Engine**: MapLibre GL JS
- **Tiles**: OpenFreeMap
- **Flags**: FlagCDN
